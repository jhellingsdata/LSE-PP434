The one idea

So far, our charts have had one interaction: the tooltip. There are two more kinds:

  • Widgets: the reader sets a value with a control under the chart (a dropdown, radio buttons, a slider, a checkbox).
  • Selections: the reader acts on the chart itself (hovering, clicking, clicking the legend, dragging a box).

Both work the same way. Every interaction is a param plus a place that uses it. A param is a named value that can change while someone is looking at the chart. You use it in a filter, a calculation, a mark property, a condition or a title, and the chart updates when it changes.

1. Widgets

The recipe: start with a hard-coded value, give it a name as a param (the chart doesn't change), then add bind to get a control. These five steps use the Week 8 menu prices.

Don't call a param item. Vega uses that name itself, and the chart fails with "item is not defined". That's why ours is called dish.

2. Selections

The recipe: (1) make a selection, (2) use it in a condition, (3) choose the trigger. Every step below makes one change to the one before, on the same chart: GDP per person and life expectancy, coloured by continent.

No encoding, no legend. A legend only exists when an encoding (colour, size, shape) makes one. Bind the selection to the field the legend shows. In a layered chart, put the selection on the first layer, or legend clicks do nothing (see the lecture's S2).

When an interaction doesn't work

SymptomLikely cause and fix
"item is not defined"A param called item: rename it.
The dropdown appears, but nothing changesThe filter still uses the hard-coded value. Use the param's name, without quotes: datum.item == dish.
Clicking the legend does nothingNo colour (or size, or shape) encoding, so no legend to bind to; or, in a layered chart, the selection isn't on the first layer.
Hover does nothingThe selection is on a layer with no points to pick (a line), or the on trigger is missing.
The colour picker starts blackA colour input needs a hex code: "#ff0000", not "red".
A fit line or total silently failsNumbers read as text. JSON isn't type-guessed, and one word (like null) in a CSV column makes it text: add "format": {"parse": {"value": "number"}}.
A year slider map hardly changesThe colour scale refits every year. Fix its domain: "scale": {"domain": [2.25, 4.25]}.
