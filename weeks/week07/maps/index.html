Lecture practical: from an x/y chart to a map

A point map is a scatter plot. Longitude and latitude are just x and y, in degrees instead of pixels. A projection is a scale for the whole Earth: it turns degrees into pixels. A base map is more of the same: shapes made of [longitude, latitude] points, drawn with the same projection. These six steps build up one idea at a time.

1. Base maps

A map file (GeoJSON or TopoJSON) holds shapes. The geoshape mark draws them, and a projection flattens the round Earth onto the page. Our map-data files are TopoJSON, with the shapes in a group called geog, so the data needs "format": {"type": "topojson", "feature": "geog"}.

GeoJSON

Many map files online are GeoJSON: a list of features, so the data needs "format": {"property": "features"}. Otherwise, everything works the same.

2. Point maps: layers

Point data is a table with a latitude and longitude for each row. To give the points context, we draw two charts in one: the base map first, then the points on top. This is a layer.

3. Choropleth maps: lookups

A choropleth colours each area by a value. The map has a code for each area (properties.id), and our CSV has the same codes (geo_id) with a value for each. A lookup transform matches the codes and copies the value onto each shape. Start with a lookup on its own, without a map:

Why did my map go blank (or show the wrong year)? A lookup keeps only one matching row for each area. If your CSV has a row for every year, use the pattern below: start with the CSV, filter to one year, then look up the shapes.

4. Devolution

England's strategic authorities (formerly combined authorities) are groups of councils that take on powers from central government. Wales has four regional Corporate Joint Committees. Boundaries and tiers come from map-data's strategic authorities guide, which also has a folder for each authority, with its councils and small areas.

Data for every strategic authority and council in England (and some for Wales) is in weeks/week07/data/msa: its README explains what each file measures and which map file to use with it.

5. Going further

A recipe for any map

  1. Find a base map for your areas (see map-data, or the ONS Open Geography Portal). Copy its raw GitHub link.
  2. Draw it with a geoshape mark. If nothing appears, check the format: TopoJSON needs the right feature name; GeoJSON needs "property": "features".
  3. Find the area codes in the map: add a tooltip with properties.id (or open the file and look).
  4. Get your data with one row per area, and a column with the same codes. Check they match: same type of area, same year of boundaries, no missing leading zeros.
  5. Add the lookup: "lookup" is the code in the map, "key" the column in your CSV, "fields" the columns to copy.
  6. Finish it: colour scheme, legend title, tooltip, title and source. Show missing data in grey.
  7. Export and embed the JSON on your website, as in Week 3.

Making map files smaller

Official boundary files are very detailed, and can be tens of megabytes: too slow for a web page. Aim for under about 500 KB. mapshaper.org simplifies them in your browser: drag in the file, click Simplify (tick prevent shape removal), drag the slider to about 5%, then Export as TopoJSON. In our example, a 1.5 MB file of Welsh councils became 17 KB.

Read the full mapshaper guide: formats, where to find boundaries, filtering and merging areas, and fixes for blank or "inside out" maps.
